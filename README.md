# 🧮 Scientific Calculator

A modern, futuristic scientific calculator built with **React, TypeScript, Vite, and Tailwind CSS**.

It provides basic and scientific calculations, equation solving, LCM/HCF calculations, calculation history, keyboard support, and a responsive cyberpunk-inspired interface.

**Developed by Shaik Mohammed Mustak**

## ✨ Features

### 🧮 Basic Calculator
- Addition, subtraction, multiplication and division
- Percentage calculations
- Brackets
- Keyboard support
- Decimal calculations

### 🔬 Scientific Calculator
- `sin`, `cos`, `tan`
- Inverse trigonometric functions
- `log` and `ln`
- Square root
- Powers
- π and e
- DEG / RAD mode
- Standard trigonometric values
- Handles undefined values such as `tan(90°)`

### 📐 Equation Solver
- Solves linear equations
- Step-by-step working
- Example: `2x + 5 = 15`
- Formula reference

### 🔢 LCM & HCF
- LCM calculator
- HCF calculator
- Step-by-step working

### 📜 Calculation History
- Stores previous calculations
- Shows calculation type
- Timestamp
- Copy calculation result

### 🎨 User Interface
- Futuristic cyberpunk design
- Neon blue theme
- Glassmorphism UI
- Animated particle background
- Welcome typewriter animation
- Responsive design
